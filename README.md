# notion-embeds-typestyle

給 Notion 用的置中文字嵌入工具。Notion 原生不能置中文字，這個頁面用嵌入（`/embed`）的方式補上。

## 用法

1. 直接打開部署後的網址（不帶參數），會看到產生器。
2. 輸入文字、調整顏色／字重／對齊，用「手機 390／小手機 320」預覽。
3. 按「複製」取得嵌入網址，在 Notion 輸入 `/embed` 貼上，拉好高度即可。

字級會依嵌入框寬高自動縮放到剛好放得下，手機不會爆版。

## 網址參數

| 參數 | 說明 | 預設 |
|---|---|---|
| `t` | 文字，`|` 換行；`*字*` 套強調色 | （必填） |
| `c` | 文字顏色（hex，不含 #） | `2f6b55` |
| `hc` | 強調色 | `4a9a6e` |
| `s` | 最大字級 px | `48` |
| `w` | 字重 | `700` |
| `lh` | 行高 | `1.5` |
| `ls` | 字距 em | `0` |
| `a` | 對齊 `center` / `left` / `right` | `center` |
| `bg` | 背景色 hex，省略為透明 | 透明 |
| `p` | 內距 px | `8` |

範例：`?t=別再頭痛醫頭|消耗時間、金錢了！&c=2f6b55&s=56&w=700`

## 部署（Cloudflare Pages）

Workers & Pages → 建立 → Pages → 連接到 Git，選擇此 repo，建置設定如下：

| 欄位（英文介面） | 中文意思 | 填寫 |
|---|---|---|
| Framework preset | 框架預設 | `None`（無） |
| Build command | 建置指令 | 留空 |
| Build output directory | 建置輸出目錄 | `/` |

純靜態 HTML，不需要建置；之後推送到 `main` 會自動重新部署。
